Phantom Blade Zero における **Breached State** は、戦闘中に直面しうる最も危険な状態であり、すべての Soul プレイヤーは最終的にそれを乗り越える方法を学ばなければなりません。これは **Sha-Chi ゲージ** がゼロになった瞬間に発生し、通常ダメージを緩和するエネルギー障壁が剥奪されます。もしボスが突然HPバーの半分を削る理由、あるいは些細な攻撃の連鎖でなぜキャラクターが地面に転倒するのか疑問に思ったことがあるなら、その答えはほぼ必ずこの単一のメカニクスに起因しています。Phantom Blade Zero の Breached State を理解することは、ランを守るかセーブファイルを崩壊させるかの違いであり、このゲームは回復ウィンドウを無視するプレイヤーを極めて厳しく罰します。

## Phantom Blade Zero における Breached State とは

Breached State は、**Sha-Chi ゲージ** がブロックされたダメージ、部分的なパリー、またはバリアを直接回避する特定の敵攻撃によって完全に消費された瞬間に発動する防御失敗条件です。[Steam](https://store.steampowered.com/app/4115450/Phantom_Blade_Zero/) のストアページ説明および[公式サイト](https://pbz.s-game.com/) によると、Sha-Chi は通常のHPの上に乗る二次スタミナ層として機能し、これが枯渇すると効果的なブロックができなくなります。ゲージがゼロになると、キャラクターモデルの姿勢が可視的に変化し、Soul の周囲オーラがちらつき、 incoming 攻撃は標準的なブロック軽減を無視して命中します。

### 基本トリガー：Sha-Chi の枯渇

Phantom Blade Zero におけるすべての防御行動は、HPから引く前にまずSha-Chiから消費します。このリソースはブロックしていない間に受動的に回復し、敵に命中させることに成功すると加速します。Phantom Blade Zero の Breached State とは、単に回復が incoming プレッシャーに追いつかず、ゲージが底を突いた状態です。souls-like 出身のプレイヤーはよく見落としますが、通常のスタミナバーは変化していないように見えますが、Breached State の遭遇時に実際に重要なのはHPバーの上にあるSha-Chiリングです。

| リソース | 役割 | 回復条件 | 枯渇原因 |
|---|---|---|---|
| **HP** | 最終的な致命的バッファー | 回復アイテム、特定の能力 | ブロックされない攻撃、チップダメージ |
| **スタミナ** | 闪避、スプリント、攻撃チェーンの燃料 | 待機時間 | 闪避、スプリント、軽攻撃 |
| **Sha-Chi** | ブロックバリア / パリー触媒 | 敵に命中、待機（ゆっくり） | 攻撃のブロック、部分的パリー |

この経済の最下段が崩壊すると、その後のすべてのブロックは盾がないかのように振る舞い、[Phantom Blade Zero Tips And Tricks](/ja/guides/tips-and-tricks/) の解説によるコミュニティテストで推定される30〜40パーセントの incoming ダメージ増加を受けます。

## Breached State は戦闘をどう変えるか

Phantom Blade Zero の Breached State に入ることは、静かなステータス効果ではありません。これは数秒間、ゲームがキャラクターを扱う方法を根本的に書き換えます。Soul は受動的チップ吸収を失い、パリーのタイミングウィンドウが狭まり、特定の敵コンボストリングは通常バリアで弾かれる追加ヒットを獲得します。

### ブロックと防御ペナルティ

Breached 中、ブロックはもはや安全なチップダメージ値にダメージを軽減しません。これは、単一のガード済みヘビー攻撃でもHPプールのかなりの部分を削ることを意味します。このウィンドウ中のパリー試行も異なる挙動を示します：アクティブパリーフレームが収縮し、テレグラフされた攻撃に完璧にタイミングの合った入力のみが成功します。このウィンドウでの急いだパリーは、通常、スタンガーとなり、実質的に生のダメージを食らうのと同じです。

| 防御オプション | 通常状態 | Breached State |
|---|---|---|
| ヘビー攻撃をブロック | 約10%チップダメージ | 約65%生ダメージ |
| 軽ブロック | 無視できるチップ | 約25%生ダメージ |
| パリーウィンドウ | 9アクティブフレーム | 5アクティブフレーム |
| ブロックスタミナ消費 | 標準 | 1.5倍乗数 |

[Phantom Blade Zero How To Parry](/ja/guides/how-to-parry/) ガイドを読んだことがあるなら、そこにあるパリーテーブルは同じウィンドウ測定値を示しており、リアルタイムの戦闘でペナルティを一目で把握しやすくなっています。

### アニメーションと回復ウィンドウ

Breached State はまた、短い回復ロックアウトを導入します。Sha-Chi が最初にゼロになると、キャラクターは約0.5秒間躓き、これは高速の敵に対してポジショニングを失うのに十分な時間です。闪避の回復ウィンドウはやや拡大します（Soul が本能的に回避に傾くため）、しかし闪避ごとのスタミナ消費増加は、スタミナバーを空にせずに安全な場所へロールを連打できないことを意味します。これが、多くの経験豊富なプレイヤーがBreached State と [Phantom Blade Zero Ghostep Explained](/ja/guides/ghostep-explained/) テクニックを組み合わせる理由です。このテクニックはスタミナの代わりにSha-Chiを燃料として使用します。

## Breached State を強制する敵

Phantom Blade Zero のすべての敵が、生ダメージのみを通じてBreached State に追い込むわけではありません。一部の遭遇戦は、マルチヒットプレッシャー、エレメンタル効果、またはバリアを設計上回避するグラブ攻撃によってSha-Chiゲージを削るように特別に設計されています。

| 敵カテゴリ | Breached トリガー | 一般的な発生場所 |
|---|---|---|
| **Crimson Warden** ボス | スタンガー後の5ヒットコンボ | Sunken Chapel, Ash Quarter |
| **Shattered Cultist** 雑魚 | 3回の素早い斬撃コンボ | Wrecked Dockyards |
| **Pale Ronin** ボス | グラブ攻撃がSha-Chiを完全に無視 | Forgotten Dojo |
| **Ash-Touched Hound** 雑魚 | 火属性チップが時間とともにバリアを消耗 | Cinder Tunnels |

**Crimson Warden** は特に有名です。なぜなら、彼のフェーズ2のオープナーは、プレイヤーが最初のフェーズで自然にSha-Chiが低くなるタイミングでちょうど命中するように調整されており、準備の整っていないプレイヤーのランを wipe するカスケードするBreached State を作り出すからです。**Shattered Cultist** はより一般的な加害者であり、ほぼすべての初期エリアに出現し、多くの初心者プレイヤーがプレイ開始1時間以内に初めてBreached State を経験する理由です。

## Breached State の生存方法：戦闘戦略

Phantom Blade Zero の Breached State を生き延びることは、パニックよりも規律ある距離管理のほうが重要です。最も信頼できるアプローチは、Sha-Chi がゼロになった瞬間にきれいに距離を取ること、1回の命中で部分的なバッファーを回復し、敵のペースではなく自分のペースで再突撃することです。

### 距離確保と後退戦術

Sha-Chiリングが崩壊するのを見たら、最優先事項は距離を取ることであり、もう1回攻撃を当てることではありません。2回のバックステップでほとんどの敵をコンボリーチの外に出し、パッシブSha-Chi回復に約3〜4秒の猶予を与え、小さくても機能的なバッファーを回復できます。低Breachedゲージで最後のヒットを追いかけるプレイヤーは、ほぼ確実にそれに続くコンボを食らいます。

| 後退オプション | 確保する距離 | 回復するSha-Chi | リスクレベル |
|---|---|---|---|
| バックステップ x2 | 中程度 | 約ゲージ15% | 低 |
| 横闪避 + スプリント | 長い | 約ゲージ10% | 中程度 |
| Ghostepで離脱 | 非常に長い | Sha-Chiを消費 | 低い場合高リスク |

[Phantom Blade Zero How To Dodge](/ja/guides/how-to-dodge/) ガイドは標準スタミナ闪避の詳細をカバーしていますが、Breached State 中に上記のGhostepオプションはリスクが高いです。なぜなら、これはSha-Chiを燃料としてテレポートする必要があり、ちょうどゼロに達したばかりだからです。

### カウンターアタックのタイミング

Sha-Chiゲージの約3分の1を回復すると、カウンターアタックのウィンドウが開きます。Phantom Blade Zero の敵は1〜1.5秒続く予測可能なコンボ後回復アニメーションを持っており、このウィンドウで1回でもヘビー攻撃を当てれば、Sha-Chi回復はパッシブレートを大幅に上回る速度で加速します。これが回復ループを作り出します：離脱し、受動的に回復し、1回のパニッシュを当て、より速く回復し、ニュートラル防御に戻る。

このループを可能にするリソース層のより深いコンテキストについては、[Phantom Blade Zero Sha Chi Guide](/en/guides/sha-chi-guide/) が回復式と空のゲージを埋めるのに必要な正確なヒット回数を詳しく解説しています。

## Breached State で避けるべきミス

Phantom Blade Zero の Breached State で死ぬプレイヤーのほとんどは、3つの特定の習慣のいずれかに該当します。これらのミスを避けることは、新しいテクニックを学ぶよりも速い改善につながることが多いです。なぜなら、各ミスのコストはエンカウンター全体で複合的に蓄積するからです。

| ミス | なぜ死に至るか | より良い選択 |
|---|---|---|
| スタミナ切れでパニックロール | スタミナを消費するが無敵フレームなし | 2回バックステップし、パッシブ回復を待つ |
| テレグラフ済みヘビーへの貪欲なパリー | Breached 中ウィンドウは5フレームのみ | ブロック維持、チップを食らい、Sha-Chi回復を待つ |
| 低ゲージでの最後のヒット追いかけ | コンボ中にBreached State を発動 | 離脱し回復し、安全に再突撃 |
| Sha-Chiリングを完全に無視 | Breached 入場前に警告なし | ブロックした攻撃の後に毎回ゲージを確認 |

最も一般的なミスであるスタミナ切れでのパニックロールは、生産的であるように感じるため静かなキラーです。スタミナがなくなった後、ロールは無敵フレームのないスタミナを消費し、ゲーム開始3時間以内のBreached State 死亡のほとんどは、まさにこの順序から来ています：Breached 入場、パニックロール、それでもなおクリップ、残りHPの半分を喪失。

## よくある質問

**Phantom Blade Zero の Breached State はどのくらい続きますか？**

Breached State 自体は一瞬で起こるものです — 条件であり、タイマーではありません。Sha-Chi ゲージがゼロになった瞬間から回復が始まりますが、約20パーセントを超えるまで、ブロックは上記で説明した弱体化したBreached 状態のままです。コミュニティテストによると、 incoming ヒットなしでのパッシブ回復による完全なニュートラル防御状態への回復には、通常8〜12秒かかります。

**敵はSha-Chiを先に枯渇させずにBreached State を強制できますか？**

はい。ボスのグラブ攻撃、特定のエレメンタルDOT効果、そして中盤の敵能力の数は、Sha-Chiバリアを完全に回避し、Breached State デバフを直接適用します。**Pale Ronin** のグラブが最も明確な例であり、ブロック、スタミナ、Sha-Chiを同時に無視するため、ほとんどのプレイヤーはその特定の攻撃を一目見て闪避する方法を学びます。

**装甲や装備はBreached State のダメージを軽減しますか？**

装甲はBreached 中に受けるチップダメージを軽減しますが、条件自体の持続時間は短縮しません。重い装甲セットはBreached 乗数を1.4xから約1.25xに低下させる傾向があり、長い戦闘では有意義ですが、基礎となる回復ループは変えません。重装甲に依存するプレイヤーも、Sha-Chiを素早く回復することを依然として優先すべきです。なぜなら、ダメージ軽減は有意義ですが、繰り返しのBreached State コンボを耐えるほど保護的ではないからです。

**Breached State はPvPとPvEで同じですか？**

このメカニクスは両モードで同一ですが、PvP 対戦相手はSha-Chiリングを読み取り、PvEでは使わないようなチップコンボで意図的にBreached State に追い込むことができます。PvPでは、回復ウィンドウは熟練した対戦相手によって罰える状態と見なされるため、多くの競技プレイヤーはミラーマッチ専用にSha-Chi回復を向上させる装備ロードアウトを使用します。

**ボス戦でBreached State から回復する最速方法は？**

最速の回復チェーンは、離脱後に1回のヘビー攻撃を当てることです。なぜなら、ヒットはパッシブレートの約3倍の速度でSha-Chiを回復させるからです。ビルドによって可能であれば、Sha-Chiバッファーを一時的に付与する回復アイテムを消費するのも効果的ですが、ほとんどのボスイベントはアイテム使用のためのクリーンなウィンドウを与えません。完全なステップバイステップ回復シーケンスは、このガイドの前半にリンクされている関連Breached State 回復解説で紹介されています。
