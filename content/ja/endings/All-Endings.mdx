## ネタバレ注意

Phantom Blade Zeroには、Elden Ringの6つを上回る**8つの異なるエンディング**が用意されており、それぞれの結末が最終シネマティック、クレジット後のシーン、そしてKwang-Tsze州に住む名前付きNPCたちの運命を再形成します。すべてのエンディングを見るには、キャンペーンを少なくとも2回プレイする必要があります。Red Wraithの決断がキャラクターを単一のパスに固定してしまうからです。このウォークスルーでは、すべての結末、前提となるサイドクエスト、分岐点を整理し、コンプリート志向のプレイヤーが難しいルートを見逃すことなく全エンディングを解除できるようにし、カジュアルなプレイでは最初のプレイで最もクリーンなエンディングを得られるようにします。

[Phantom Blade ZeroのSteam](https://store.steampowered.com/app/4115450/Phantom_Blade_Zero/)ストアページによると、開発元は基本ゲームとNew Game Plus限定エンディングに分かれた8つの正規の結末を確認しており、最終対決前の計画が表面的に見えるよりもはるかに重要であることを示しています。

## 8つのエンディング構造を理解する

エンディングの構成は3つの層に分かれています。初回プレイヤーが到達できる4つの基本ゲームの結末、特定のサイドクエストによって制限される3つの分岐した結末、そして特定のアイテムの引継ぎが必要な1つのNG+の結末です。各エンディングにはエピローグギャラリーに影響するクレジット後のフラグもあり、日誌は各フラグを個別に記録します。

### 基本ゲーム対New Game Plusのエンディング

最初のプレイでは、**The Phantom Unbound**という1つのエンディングだけがロックされます。他のすべての結末は最初からやり直さなくても到達可能ですが、そのうち2つは特定のサイドクエストを特定の順序でプレイする必要があり、見逃しやすいです。NG+では、**Inkwell Pendant**が以前のセーブデータから引き継がれている場合にのみ表示される、Red Wraithとの隠し会話オプションが導入され、最終対決に第二の層が追加されます。

| 層 | 利用可能なエンディング | 必要なセーブデータ | 見逃しの可能性 |
|---|---|---|---|
| 初回プレイ | 8つのうち7つ | 新規セーブ | The Phantom Unbound |
| 2回目のプレイ (NG+) | 8つのうち8つ | Inkwell Pendant引継ぎ | NG+開始後はなし |
| 3回目のプレイ (NG+2) | 8つのうち8つ | 全フラグ引継ぎ | なし |

### キャンペーンを通じて選択がどのように連鎖するか

Phantom Blade Zeroは、**Judgment Log**と呼ばれる隠された台帳を通じてプレイヤーの選択を追跡します。これは**Order Reputation**、**Lotus Reputation**、**Wraith Reputation**の3つの指標を集計します。各サイドクエストはこれらの値の1つまたは2つを調整し、最終対決では関連するエンディングカットシーンを表示する前に、合計値を固定の閾値と照合します。台帳は最終セーブ時にのみ確定するため、キャンペーン途中でのセーブデータの使い回しにより、進行状況を失うことなく異なる結末を試すことができます。

戦闘レイヤーに不慣れなプレイヤーは、分岐する物語に飛び込む前に[Phantom Blade Zero 初心者ガイド](/ja/guides/beginner-guide/)で基本を学ぶことができます。一部のエンディングでは、最終アリーナに登場するボスのフェーズも変化するからです。

## 難易度別にランク付けされたすべての結末

以下は、ブラインドでの初回プレイで解除する難易度順に並べた、全8エンディングの完全なリストです。ここでの難易度は戦闘ではなく、前提となるサイドクエストチェーンを指します。戦闘の規模はすべてのパスで同じようにスケールするためです。

| エンディング | 前提条件 | 難易度 | 評判トリガー |
|---|---|---|---|
| The Penitent Blade | デフォルトパス | 簡単 | Order ≥ 30 |
| The Wraith's Bargain | Red Wraithを助命 | 簡単 | Wraith ≥ 40 |
| The Wraith's End | Red Wraithを殺害 | 簡単 | Order ≥ 50 |
| The Order Restored | Orderチェーン完了 | 普通 | Order ≥ 70 |
| The Lotus Path | Lotusチェーン完了 | 普通 | Lotus ≥ 60 |
| The Broken Vow | Mourner's Vow失敗 | 難しい | 混合トリガー |
| The Mourner's Shadow | Mourner's Vow完了 | 難しい | 混合トリガー |
| The Phantom Unbound | NG+のみ、Inkwell Pendant | 非常に難しい | NG+台帳 |

### サイドクエスト依存のエンディング

8つのエンディングのうち5つは、最終ボスのトリガー前にオプションのサイドクエストラインを完了する必要があります。これらのチェーンのうち3つ — **Order of the Black Veil**チェーン、**Whispering Lotus**チェーン、**Mourner's Vow**チェーン — はそれぞれ約2時間かかり、Sunken Chapel、Alabaster Quarter、Hollowed Tunnelsに散らばっています。いずれかのチェーンをスキップすると、そのプレイでは対応する結末がロックされ、チェーンが放棄された場合のゲーム内警告はありません。

## Red Wraithの決断分岐

Red Wraithはキャンペーン中に3回登場します。Alabaster Quarterでの奇襲、Hollowed Tunnelsでのミニボス、そして最終アリーナでのいくつかのエンディングへの門番としてです。判断の選択は2回目の遭遇時に行われますが、Wraithを助命するか処刑するかの選択肢が表示されるかどうかは、プレイヤーの台帳の値によって決まります。

| 選択 | 戦闘の変化 | 最終対決 | 解除されるエンディング |
|---|---|---|---|
| Red Wraithを助命 | Wraithが第二フェーズをスキップ | Wraithが共に戦う | The Wraith's Bargain |
| Red Wraithを処刑 | ボーナス戦利品ドロップ | WraithがShadeに置き換わる | The Wraith's End |
| Red Wraithを無視 | デフォルトの動作 | 標準的な決闘 | The Penitent Blade |
| 助命 + 高いWraith Rep | Wraithが最終フェーズをスキップ | 隠し会話が開く | The Phantom Unbound (NG+) |

### Red Wraithの選択が実際に変えるもの

Wraithを助命することを選択すると、ボスルームがWraithが独立して巡回する2つのゾーンに分割されるため、最終対決のアリーナレイアウトが変更されます。これにより戦闘は容易になりますが、プレイヤーはRed Wraithの固有武器ドロップを入手できなくなります。Wraithを処刑すると、**Crimson Brotherhood**アーマーセットが解除され、Order Reputationの台帳がThe Order Restoredの閾値を自動的に超えるため、スピードランナーは最速のクリーンなエンディングのために処刑ルートを好みます。The Phantom Unboundパスは、Wraithの助命と、以前のセーブからのInkwell Pendantの保持の両方を必要とし、これはゲーム全体で唯一の複数セーブデータに依存する要素です。

最終対決のパリィのタイミングについて復習が必要な場合は、[Phantom Blade Zero パリィの方法](/ja/guides/how-to-parry/)ガイドで、Wraithフェーズが要求する正確なタイミングを確認できます。

## エンディングを形作るサイドクエスト

6つのオプションのサイドクエストがJudgment Logに影響を与え、いずれかを逃すと、そのプレイから1つのエンディングが静かに削除されます。以下の表は、各クエスト、そのトリガーが見つかる場所、変更される台帳の値を示しています。すべてのクエストトリガーは見逃しやすいため、クエストラインを放棄した場合は引き返す必要があります。

| サイドクエスト | トリガー場所 | 台帳の値 | 解除されるエンディング |
|---|---|---|---|
| The Forgotten Oath | Sunken Chapelの祭壇 | Order +15 | The Order Restored |
| Whispering Lotusの入信 | Alabaster Quarterの茶屋 | Lotus +20 | The Lotus Path |
| Mourner's Vow パート1 | Hollowed Tunnelsの祠 | Mixed +10 | The Mourner's Shadow |
| Mourner's Vow パート2 | Crimson Wardenの隠れ家 | Mixed +10 | The Mourner's Shadow |
| Crimson Brotherhoodの入信 | Capitalの兵舎 | Order +25 | The Order Restored |
| Wraith's Memory | Wraith後の隠し床の間 | Wraith +20 | The Wraith's Bargain |

### ルートをロックまたは解除するクエストの順序

**Crimson Brotherhood**チェーンの前に**Whispering Lotus**チェーンを完了すると、BrotherhoodのNPCがLotusの属性に否定的に反応するため、Order Reputationの台帳が10減少します。この相互作用は、Lotus属性のプレイにおける最もクリーンな最初のエンディングはThe Lotus Pathであり、最もクリーンなOrder属性のプレイは、The Forgotten Oathクエストラインが完了したかどうかに応じてThe Penitent BladeまたはThe Order Restoredであることを意味します。Mourner's Vowチェーンは、LotusとOrderの両方の値を同じ方向に押し上げる唯一のクエストラインであり、これがコンプリート志向のプレイヤーにとって推奨される出発点である理由です。

これらのクエストボスに対する戦闘準備のより広範なコンテキストが必要なプレイヤーは、[Phantom Blade Zero 戦闘ガイド](/ja/guides/combat-guide/)を読んで、各ミニボスに最もクリーンに対処できる武器の装備を確認できます。

## New Game Plusのエンディングとリプレイ戦略

Phantom Blade ZeroのNG+では、ほとんどの装備、すべての解除された外観アイテム、そして重要なことに、前回のプレイのSunken Chapelセクションで収集された場合、**Inkwell Pendant**が引き継がれます。このペンダントは、最終アリーナでRed Wraithとの隠し会話オプションを解除する唯一のアイテムであり、これがないとThe Phantom Unboundエンディングはどのセーブデータでも到達できません。

### New Game Plusで変わること

| 要素 | 初回プレイ | New Game Plus |
|---|---|---|
| 敵のHP | 基準値 | +50% |
| 敵のダメージ | 基準値 | +30% |
| アイテム引継ぎ | なし | ほとんどの装備 |
| Inkwell Pendantの効果 | 外観のみ | 隠し会話を解除 |
| ボスのパターン | 基準値 | ボスごとに1つの新攻撃 |
| Judgment Logの閾値 | デフォルト | 同じ閾値、新しいフラグを追跡 |

隠し会話は、最終アリーナでWraithが助命された後に表示され、その会話で2番目の選択肢を選ぶと、基本ゲームからのいくつかの未解決のストーリーラインを解決するユニークなカットシーンがトリガーされます。これが、**The Phantom Unbound**がスロット8にあるにもかかわらず、コミュニティによって正規の結末として扱われている理由です。

### コンプリート志向のプレイヤーに推奨されるリプレイパス

すべてのエンディングへの最速ルートは、3つのセーブデータ計画です。1回目はOrder属性のエンディング（The Penitent Blade、The Order Restored、The Wraith's End）に焦点を当て、2回目はLotus属性のエンディング（The Lotus Path、The Mourner's Shadow、The Broken Vow）に焦点を当て、3回目はInkwell Pendantを入手してThe Phantom Unboundを解除するNG+です。サイドチェーンを完了した場合、各プレイには約18時間かかります。つまり、完全なコンプリートパスは合計で約54時間になります。

各リプレイからより多くの価値を引き出したいプレイヤーのために、[Phantom Blade Zero ヒントとコツ](/ja/guides/tips-and-tricks/)の記事では、コンプリートルートから数時間を短縮するセーブデータ使い回し戦略を紹介しています。

## よくある質問

**Phantom Blade Zeroにはいくつのエンディングがありますか？**

Phantom Blade Zeroには合計**8つの異なるエンディング**があります。7つは初回プレイで利用可能で、8つ目の**The Phantom Unbound**は、特定の引継ぎアイテムを持ったNew Game Plusプレイでのみロック解除されます。

**Red Wraithの選択はエンディングを固定しますか？**

はい。Hollowed Tunnelsでの遭遇中にRed Wraithを助命するか処刑するかを選択すると、セーブデータがWraith Reputationの台帳にコミットされ、新しいプレイを開始しない限り、反対の結末には到達できなくなります。

**すべてのエンディングを見るために、すべてのサイドクエストを行う必要がありますか？**

いいえ。初回プレイの7つのエンディングはそれぞれ独自のクエストラインのみを必要としますが、**Whispering Lotus**、**Crimson Brotherhood**、または**Mourner's Vow**チェーンを逃すと、そのプレイから対応するエンディングが永久に削除されます。

**Phantom Blade Zeroの正規エンディングは何ですか？**

コミュニティは、最も多くの未解決のストーリーラインを解決し、解除に最も高い労力を必要とするため、**The Phantom Unbound**を正規の結末として扱っていますが、開発元は公式に正規ルートを確認していません。

**初回プレイでThe Phantom Unboundを入手できますか？**

いいえ。The Phantom Unboundエンディングは、以前のセーブから引き継がれた**Inkwell Pendant**と特定のNew Game Plusの会話オプションを必要とするため、最初にNG+を開始しない限り解除できません。

次のプレイで最初に追いかける予定のエンディングは何ですか？また、Wraithルートを早期に確定させるために、どのサイドクエストチェーンをスキップするつもりですか？
