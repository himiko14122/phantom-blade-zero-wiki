## Phantom Blade Zeroには何本のエンディングがあるのか？

Phantom Blade Zeroには8つの異なるエンディングが収録されており、これはElden Ringの6本より2つ多く、2026年にリリースされたアクションRPGの中でも特に大きなエンディング構造を誇ります。すべてのエンディングは、サイドクエストの完了、中盤の対話選択、そして最終的な赤い亡霊の決断が組み合わさって決定します。この最終決断は最終戦に直接影響を与えます。これらのトリガーの多くが一本の不可逆パス上に存在するため、プレイ中に気づかないプレイヤーは、最初のプレイで2〜3ルートをロックしてしまうのが一般的です。エンディングは寺院の ruins での**業 convergence（カルマ的収束）**後の最終ムービーで上映され、クレジット後のスタッフロール後のショートシーンは、赤い亡霊に味方したか、契約を断ったかによって変化します。

| エンディング名 | 主なトリガー | 解除難易度 |
|---|---|---|
| Severed Pact（断ち切られた契約） | 最終戦で赤い亡霊の提案を拒否する | 易 |
| Karmic Bond（業の絆） | 赤い亡霊の提案を受け入れる | 易 |
| Hollow Return（虚無の帰還） | 3つ未満のサイドクエストを完了する | 易 |
| Forgotten Brother（忘れられた兄弟） | Yunの全サイドチェーンを完了し、赤い亡霊を拒否する | 中 |
| Wraith Ascendant（亡霊の昇天） | 赤い亡霊を受け入れ、すべての派閥クエストを完了する | 中 |
| Silent Burial（沈黙の埋葬） | 忘れられた図書館で学者を死なせる | 中 |
| Crimson Echo（紅の響き） | 裁判の後に裁判官を許す | 難 |
| Eternal Cycle（永劫の輪廻） | 全サイドクエスト完了＋カルマ的収束での特定対話フラグ | 難 |

## エンディングを決定する主要な選択分岐

エンディングツリーを支配する2つの選択分岐は、カルマ的収束での**赤い亡霊の決断**と、ゲーム内の非表示カウンターが静かに追跡する**サイドクエスト完了閾値**です。ほとんどのプレイヤーはこのカウンターをUI上で確認できませんが、コミュニティの検証により、利用可能な7つのサイドチェーンのうち少なくとも5つを完了すると、**共感変数（Compassion Variable）**と呼ばれる内部フラグが上がることが確認されています。この閾値に達しないと、最も難しい2つのエンディングにアクセスできず、赤い亡霧の最終決断をどう選んでも虚無の帰還または業の絆のエンディングに固定されてしまいます。そのため、完璧主義者がすべてのエンディングを見るには、サイドクエストの grinding は必須です。

### カルマ的収束での赤い亡霊の決断

赤い亡霊は、寺院の門の**双子の番人（Twin Sentinels）**を倒した後に発動するクライマックスのカットシーン「カルマ的収束」であなたに立ちはだかります。3つの対話選択肢が提示されます。契約を受ける（業の絆または亡霊の昇天を解放）、拒否する（断ち切られた契約または忘れられた兄弟を解放）、沈黙する（事前フラグに応じて沈黙の埋葬または永劫の輪廻）。これはセーブスキャミングによって再訪問できない、ゲーム内で唯一の決断です。なぜなら、カルマ的収束は対話前にオートセーブし、選択後に即座に上書きするためです。クリーンなやり直しをしたい場合は、前の章の手動セーブを読み込む必要があります。そのため、**専用エンディングラン**は、オートセーブをその場でリロードするよりもはるかに効率的です。

### サイドクエスト完了と非表示の共感変数

Phantom Blade Zeroのサイドクエストは6つの地域に散在し、7人の名付きNPCに紐づいています。各チェーンは2〜4段階あり、攻撃的な対話選択やランダム遭遇で重要なNPCを倒すことで段階を失敗させることができます。**共感変数**は、完了したチェーンごとに1ポイント上昇し、ボス戦場外でNPCを処刑するごとに2ポイント減少します。変数は0から開始し、最も難しいエンディングには5ポイントが必要です。そのため、探索中に商人を1人でも殺すと、永劫の輪廻が画面上の警告なしに永久に閉じてしまい、平和主義の自制は実際の戦略的選択となり、演出テキスト以上の意味を持ちます。

## サイドクエスト完了ルートと見逃し窓口

いくつかのサイドチェーンには、地域を離れた後に閉じるハードな見逃し窓口があり、ゲームはその遷移時に通知を表示しません。すべてのエンディングを解放したい場合は、以下のチェーンを優先保存として扱う必要があります。特に各地域を初めて訪れる際に重要です。[Phantom Blade Zero ビギナーガイド](/ja/guides/beginner-guide/)のウォークスルーに従っているプレイヤーはすでに大部分に触れていますが、エンディング固有のトリガーはカジュアルな最初のプレイよりも意図的なタイミングを要求します。

| サイドクエスト | NPC | 地域 | 見逃し窓口 | 解放するエンディング |
|---|---|---|---|---|
| The Scholar's Last Letter（学者の最後の手紙） | Master Yu | Forgotten Library | 図書館ボス後 | Silent Burial, Eternal Cycle |
| Yun's Lost Brother（ユンの失われた兄弟） | Yun | Jade Hollow | Jade Hollow離脱後 | Forgotten Brother, Eternal Cycle |
| The Magistrate's Trial（裁判官の裁判） | Magistrate Luo | Tribunal City | 裁判カットシーン後 | Crimson Echo |
| Faction of the Pale Moon（苍白の月の派閥） | Pale Moon envoys | Frostfall Pass | 二人ボス後 | Wraith Ascendant |
| The Merchant's Debt（商人の借金） | Old Chen | Riverside | なし（常に利用可能） | 共感変数上昇 |
| The Wandering Monk（放浪の僧侶） | Brother Kai | Sunken Chapel | チャペルボス後 | Eternal Cycle |
| Red Wraith's Origin（赤い亡霊の起源） | Memory shard | Any post-game | NG+のみ | Wraith Ascendant, Eternal Cycle |

### 初回プレイのための優先保存ポイント

コミュニティフォーラムで報告されている最も一般的なミスは、忘れられた図書館で**Master Yu**の lectern に置かれた手紙を読まずに通り過ぎることです。その手紙は沈黙の埋葬のトリガーであり、図書館のボスを倒すと部屋が崩壊し、チェーンが永久に封印されます。2番目に見逃されやすいチェーンは、Sunken Chapelの**放浪の僧侶**です。Brother Kaiは夜間のみ出現し、チャペルには日中に利用できる高速移動機能があるため、ほとんどのプレイヤーは日中にチャペルを利用します。高速移動に頼ると彼に会えないため、[Phantom Blade Zero Tips And Tricks](/ja/guides/tips-and-tricks/)ガイドでは、地域を離れる前に少なくとも1回、日没から夜明けまでの間にすべてのチャペルを手動で探索することを推奨しています。

### 非表示カウンターの実際の動作

公式Discordに投稿されたコミュニティデータによると、共感変数は3つの時点でチェックされます。Tribunal Cityのメインクエスト後、Frostfall Passのメインクエスト後、およびカルマ的収束の最終局面です。カルマ的収束に到達した時点でカウンターが4以下の場合、対話ツリーが縮小し、永劫の輪廻の分岐なしに受容か拒否の二択のみになります。5に達すると、Brother Kaiのチェーンも完了している場合にのみ表示される隠し第三選択肢が解放されます。そのため、カウンター単独では不十分で、プレイヤーはカウントと特定のNPCスレッドの両方を完了する必要があります。

## シークレット・隠しエンディングの解放方法

最も難しい2つのエンディングは**Crimson Echo**と**Eternal Cycle**で、どちらも極度の自制力または利用可能なすべてのサイドチェーンのほぼ完璧な完了を必要とします。Crimson Echoは1つの決断のみに依存するため、2つの中で simpler です：裁判のカットシーン中に裁判官を処刑するのではなく許す必要があります。ゲームはこれを慈悲ある選択として提示しますが、実際の結果はベースゲームで最も暗いエンディングです。なぜなら、裁判官はクレジット後のスタッフロール後にプレイヤーの派閥を裏切り、ほとんどのプレイヤーは2回目のプレイで初めてそれを目にするからです。

### Eternal Cycleの事前最終条件

Eternal Cycleは、**Sha-Chi flow system**（パリーのタイミング）と**Breached state recovery**（体力が2回目の起き上がり閾値を下回った時に発動するメカニクス）を含む、ゲームが提供するすべてのメカニクスに参加することを唯一必要とするエンディングです。このエンディングを解放するにはこれらのシステムが上手である必要はありませんが、各メインボスの後にBrother Kaiと話し、すべてのシャリンで少なくとも1つのSha-Chi試練を完了する必要があります。これらのやり取りがEternal Cycleをゲートする非表示カウンターに貢献するためです。初回プレイでシャリンをスキップした場合、2回目のプレイでも再訪しないと資格を満たさず、シャリンとのやり取りはオプションコンテンツではなく、過小評価された進行要件となります。

### 最終ボスの決断結果

カルマ的収束の最終ボスは、プレイヤー自身のキャラクターの腐敗したバージョンとの2フェーズ戦いで、コミュニティでは**Mirror Sentinel（鏡の番人）**と呼ばれています。第1フェーズは、Mirror Sentinelがあなたの直前の3つの動きを1:1で鏡写しにするため、[combat fundamentals](/ja/guides/combat-guide/)の練習を積んだプレイヤーに報酬を与えます。第2フェーズは、ボスがパリーでしか中断できない不可ブロックの攻撃で開始するため、パリーのタイミングの達人に報酬を与えます。戦いの後の3番目の対話選択肢を選ぶと、共感変数に応じてQTEがCrimson EchoまたはEternal Cycleに分岐し、その瞬間が非常にゲートされている理由と、ボスに負けると手動リロードなしに選択を再試行できない理由を説明します。

| 最終選択 | 共感変数 | 結果となるエンディング |
|---|---|---|
| 契約を受容 | Any | Karmic Bond |
| 契約を拒否 | Any | Severed Pact |
| 沈黙する | 0-3 | Silent Burial |
| 沈黙する | 4 | Forgotten Brother |
| 第三選択肢 | 5+ | Eternal Cycle |
| 事前に裁判官を許す | 5+ | Crimson Echo（上書き） |

## NG+エンディング：変わるものと変わらないもの

Phantom Blade ZeroのNG+は単純な難易度アップではなく、元の8本から分岐する2層のエンディングルートを追加します。NG+固有の1つのエンディングと、赤い亡霊の起源に紐づく特定のNG+サイドクエストを必要とする1つを含みます。コミュニティでは、ベースの8つのエンディングはNG+でも到達可能であることが確認されていますが、**Red Wraith's Origin**メモリスパーンは少なくとも1回クリアした後にのみ出現するため、最初のプレイでは100%のサイドクエスト完了でも亡霊の昇天エンディングに到達できません。Phantom Blade ZeroのNG+エンディングは、パッシブな発見ではなく、意図的な2回目のコミットメントを必要とします。

### NG+固有エンディング

2つのNG+固有エンディングは**Reforged Bond**と**Twin Flame**で、どちらもベースゲームのすべてのエンディングを少なくとも1回目に視聴した後にのみ利用可能になります。Reforged Bondは、1回目のプレイで拒否した赤い亡霊の提案をNG+で受容した場合に再生されます。これはゲームがセーブファイルに保存された非表示フラグで追跡します。Twin Flameは、Eternal Cycleエンディングを既に完了した状態でNG+に入った場合にのみ再生されます。カルマ的収束が以前の選択を認識し、1回目のプレイでは存在しなかった4番目の対話選択肢を解放するため、NG+ランには単なるステットリセットではなく、独自の物語の質感が与えられます。

### 継承選択とリセットメカニクス

ほとんどのサイドクエスト完了フラグはNG+に継承されるため、ベースゲームで7つのチェーンすべてを完了したプレイヤーは、対話フラグの要件も満たせば、最初のNG+プレイで即座にEternal Cycleにアクセスできます。ただし、**共感変数はNG+開始時に、前回のプレイで何をしたかに関わらず0にリセットされます**。これにより、エンディング資格を維持するにはすべてのチェーンを再プレイする必要があります。このリセットは意図的なデザインであり、開発者はNG+を「継続」ではなく「新たな審判」として体験させたいと考えています。[公式サイト](https://pbz.s-game.com/)のロアタブでは、このメカニクスを「カルマの再コミットメント」と表現しています。ベースのエンディング数に関する権威あるリファレンスとしては、[Phantom Blade ZeroのSteamストアページ](https://store.steampowered.com/app/4115450/Phantom_Blade_Zero/)も確認できます。8本構造が説明に記載されています。

| NG+メカニクス | 継承状況 | メモ |
|---|---|---|
| Side quest completion | Yes | チャプター1からすべてのチェーン利用可能 |
| Compassion Variable | No | 0にリセット |
| Red Wraith decision history | Yes | 非表示フラグで追跡 |
| Eternal Cycle dialogue unlock | Yes | 事前に完了済みの場合 |
| Wraith Ascendant requirement | Yes | Red Wraith's Origin shard |
| Breached state training | Yes | スキル継続、シャリンリセット |

Phantom Blade ZeroのNG+エンディングをすべて効率的にスピードランしたいプレイヤーは、1回目のプレイでカルマ的収束の前に**手動セーブ**を行い、異なるサイドクエスト構成でそのセーブをリロードして複数ルートをテストすることをお勧めします。これは、カルマ的収束のオートセーブが各選択後に手動セーブを上書きするため、エンディングごとに新規NG+を開始するよりもはるかに高速です。Mirror Sentinel戦の第2フェーズのパリーウィンドウに苦労するプレイヤーは、[Breached state recovery guide](/ja/guides/breached-state-recovery/)で、死にかけの瞬間をカウンターアタックに変換する方法を確認できます。これにより、選択が表示される前に最終ボスでランが終わるのを防げます。

## よくある質問

**Phantom Blade Zeroには合計で何本のエンディングがありますか？**

ベースゲームには8つの固有のエンディングがあり、NG+は2つの固有ルートを追加して合計10本になります。すべてのエンディングを目指す完璧主義者は、最初のランでは解放できないフラグを必要とするルートがあるため、少なくとも3回のプレイを計画すべきです。

**Phantom Blade Zeroのどのエンディングが正史（カノン）エンディングですか？**

ゲームは正史のエンディングを宣言していませんが、Eternal Cycleはサイドコンテンツとの最も広範な関与を必要とし、最も長いクレジット後のスタッフロールを解放するため、物語的に最も完全なルートとして扱われています。

**Phantom Blade Zeroのすべてのエンディングを1回のプレイで取得できますか？**

いいえ。カルマ的収束は選択後にすぐにオートセーブされるため、フィナーレ前の手動セーブを読み込むか、新しいゲームを開始して他のエンディングを見る必要があります。

**Phantom Blade ZeroのすべてのNG+エンディングに到達する最も簡単な方法は何ですか？**

1回目のランですべてのサイドチェーンを完了し、赤い亡霊を拒否してから、NG+に入り、カルマ的収束で異なる対話選択を行います。このパスは、追加の grinding なしでReforged BondとTwin Flameを解放します。

**赤い亡霊の決断はPhantom Blade ZeroのNG+エンディングに影響しますか？**

はい。ゲームはあなたの以前の選択を非表示フラグで追跡し、1回目のプレイで契約を受容したか拒否したかによって異なるNG+固有ルートを解放します。そのため、ベースゲームで行った選択はNG+エンディングツリーに直接の続編を持ちます。
