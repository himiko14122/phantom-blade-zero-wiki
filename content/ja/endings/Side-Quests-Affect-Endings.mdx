Phantom Blade Zeroにおけるサイドクエストの選択は、クレジットが流れる前に体験できる8つのエンドリングのうちどれを観られるかを直接形作るため、多くのプレイヤーが思っている以上に重みを持っています。**レッドレイスの決定**はアクト3の重要な分岐点に位置しており、たった1つのクエストラインを見落とすと、フィナーレのずっと前に物語の全体の流れをロックしてしまうことがあります。特定の結末を追い求めている場合でも、全ルートを狩り求めている場合でも、サイドコンテンツがエンディングの流れにどう絡み合うのかを理解すれば、各章を計画する際の戦略が変わります。条件付きエンドリングの全容、それらをゲートするクエスト、そして最小限のプレイ回数でNG+専用の分岐を効率的に解放する方法を完全に解説します。

## エンドリング構造：8つのルート、1つの物語

Phantom Blade Zeroは8つの個別のエンドリングを搭載しており、その数はElden Ring（6つ）などのタイトルをすでに上回っており、開発者が選択駆動の結末にどれだけ力を入れたかを示しています。各エンドリングは、メインストーリーのマイルストーン、蓄積された派閥の評判、未解決のサイドクエストの状態、そしてアクト3を締めくくる**レッドレイスの決定**の組み合わせから生まれます。ゲームはクエストトラッカーを表示しないため、開発者がキャンペーンに組み込んだ全結末への意図的なルートを計画するには、潜在的なフラグシステムを理解することが唯一の方法です。

### 4つの主要分岐

8つのラベル付きエンドリングがありますが、それらはファントム協会対ジェード秩序へのあなたの忠誠心に基づいて4つの物語分岐にクラスタリングされます。分岐は以下の通りです：

| 分岐 | 核心的な決定 | サイドクエストの重み | エンドリング数 |
|---|---|---|---|
| **忠義の刃** | アクト2で魏晨を許す | 高い — 3つのサイドクエストが必要 | 2 |
| **ジェード登天** | ジェード秩序に味方する | 中程度 — 2つのサイドクエストが必要 | 2 |
| **ファントム追放** | 協会に裏切る | 高い — 4つのサイドクエストが必要 | 2 |
| **破壊された輪廻** | 両派閥から距離を置く | 低い — 1つのサイドクエスト、1つの隠しトリガー | 2 |

各分岐はさらに、アクト3の**レッドレイスの決定**が慈悲か暴力で解決されたかによって、正と負の解決に分かれ、これが4つのテーマ的パスから合計8つのルートが生まれる仕組みです。メインストーリーのみに集中するプレイヤーは、他の3つの分岐をゲートする派閥固有のクエストが盲プレイ中に見過ごされやすいことから、ほぼ確実に破壊された輪廻分岐に終わります。

### エンドゲームフラグの蓄積方法

ゲームはクエストチェックリストを表示しないため、ダイアログ選択、NPC生存状態、特定のボス戦前にオプション遭遇を完了したかどうかを静かにトラッキングします。[Phantom Blade Zero Official Site](https://pbz.s-game.com/)によると、エンジンは重み付きフラグシステムを使用しており、1つのクエストを間違った時間帯、または特定の天候条件で完了すると、ゲーム内のインジケーターなしに結果が反転する可能性があります。[Phantom Blade Zero Wikipedia](https://en.wikipedia.org/wiki/Phantom_Blade_Zero)のエントリーは、フラグシステムがオートパイロットプレイを罰するように設計されていることを確認しており、これがコミュニティテストで盲プレイの1回目のプレイで8つの可能なルートの平均5.2つのエンドリングが解放されると報告されている理由です。

## エンドリングを変えるサイドクエスト

キャンペーンにはおよそ24のサイドクエストが存在しますが、そのうち11つだけが**エンドゲームフラグの重み**を持ち、これが最終ボスに到達する時点でどのPhantom Blade Zero サイドクエスト エンドリング ルートが利用可能になるかを直接影響する唯一のものです。メインストーリーを急いだプレイヤーは、サイドクエストがアクト1と2を通じて静かに種を蒔いていたフラグ前提条件を見落とすため、典型的には破壊された輪廻分岐のみを解放します。

### レッドレイスの決定

最も重要な単一のサイドクエストチェーンは、アクト1で忘れられた神殿で**レッドレイス**に出会ったときに始まります。このキャラクターはオプションに見えるフェッチクエストを提供しますが、実際にはアクト3の最終遭遇を決定する条件を種蒔きします。レッドレイスが失われた刃を回復するのを手伝うと、フィナーレは交渉ルートとして展開され、重要なNPCの1人を許します。裏切ると、同じシーンが強制デュエルになり、エンディングルート全体が消費され、慈悲の解決へのアクセスがロックされます。

| レッドレイスの選択 | エンドリングへの影響 | 利用可能なウィンドウ |
|---|---|---|
| 刃を返す | 交渉ルート、重要な命を許す | 日没の塔のボス戦の前 |
| 刃を手元に置く | デュエルルート、交渉エンドリングをロック | 同じウィンドウのみ |
| 魏晨に報告する | 裏切りルート、派閥の重みをシフト | 同じウィンドウのみ |

神殿をスキップしてレッドレイスに全く出会わないと、両方の選択肢が除去されるため、コミュニティテストではこれがゲーム全体で最もレバレッジの高いクエストとして報告されています。[Phantom Blade Zero on Steam](https://store.steampowered.com/app/4115450/Phantom_Blade_Zero/)コミュニティは、レッドレイスに出会うことなくゲームをクリアしたプレイヤーから数百件の投稿を受けており、オプショナルクエストが彼らには見えなかったため、2つのエンドリング全体がアクセス不可能であったことを発見しました。

### サイドクエスト内の隠しトリガー

いくつかのサイドクエストは明確なエンドリング接続を持たず、しかしフィナーレが読み取るフラグを静かに種蒔きます。例えば、ランタンキーパーボス戦の前に**沈黙の地図製作者**を完了すると、開発者がSteamディスカッションボードで確認した短いエピローグシーンが解放され、そのウィンドウを見逃すと固有のポストクレジットバリアントが除去されます。これらのトリガーは条件付きダイアログに埋め込まれているため、[Phantom Blade Zero Tips And Tricks](/ja/guides/tips-and-tricks/)ガイドは、時間帯の変数のみがフラグカウンターに登録されるダイアログ行を変える可能性があるため、NPCに1回は昼間に、1回は日没後に話しかけることを推奨しています。

### 派閥ロック付きサイドクエスト

3つのサイドクエストは、ほとんどのプレイヤーが存在に気づいていない派閥評判の閾値にゲートされています。**Salt and Iron**で密輸王を助けると、忠義の刃分岐を解放するのに十分なファントム協会の評判が上がり、**The Unbound Pages**で司書を助けると、ジェード登天ルートに押し進められます。3つ目の**A Blade for a Brother**は、レッドレイスのクエストを完了し、刃を返す選択をした場合にのみトリガーされるため、二重フラグクエストとなり、ガイドなしでは1回目のプレイでは事実上見つけることが不可能です。

## NG+エンドリングと代替パス

Phantom Blade ZeroのNG+エンドリングは、単に強い敵と同じ8つのルートを再生するのではなく、1回目のプレイから特定のフラグ組み合わせを引き継ぐ必要がある2つのまったく新しい分岐を導入します。これが、完璧な戦略を持っていても盲プレイの1回目で100パーセントの完了にほとんど決して到達しない理由です。2つの固有のエンドリングは、1つのセーブファイルでは共存できない矛盾したフラグ状態を必要とするからです。

### NG+に引き継がれるもの

New Game Plusでは、以下のデータが保持され、これが複数回のプレイにわたるルート計画にとって重要です：

| 要素 | NG+に引き継がれる | エンドリングに影響 |
|---|---|---|
| エンドゲームフラグ | はい | 直接 |
| 解放されたロアエントリー | はい | 間接 |
| キャラクターレベル | はい | いいえ |
| 武器アップグレード | はい | いいえ |
| NPC記憶状態 | 一部 | 直接 |
| 派閥評判 | はい | 直接 |

NPC記憶状態のエントリーは、最も見落とされがちです。ゲームは特定のキャラクターがアクト2に生存したかどうかをトラッキングしており、その生存フラグは、キャラクターがクエストが解決する前に死亡していた場合、NG+でサイドクエストの完了を上書きする可能性があります。[Phantom Blade Zero Combat Guide](/ja/guides/combat-guide/)は、アクト2を早くクリアしてルートプランナーがオプションボス攻撃でNPCを1人も失わずにクリアしたい場合に備えたキャラクター構築方法を解説しています。

### New Game Plus固有の分岐

2つのエンドリング、**Eternal Cycle**と**Severed Path**は、1回目のプレイでは存在し得ない矛盾したフラグ組み合わせを必要とするため、2回目のプレイでのみアクセス可能です。Eternal Cycle分岐は、忠義の刃とファントム追放のフラグが同時に真であることを必要とします。これは、魏晨の決定の前にセーブを操作した場合、またはNG+を開始する前に前の進行状況を読み込んだ場合を除いて不可能です。Severed Pathは逆の条件を必要とし、すべての派閥フラグが浄化され、プレイヤーがサイドクエストの影響のないクリーンなルートを歩むことを要求します。これは、ゲームが完全クリアのプレイの後にのみ許可するものです。

## 全エンドリングを通るルートの計画

ゲームはフラグが永続的にロックされたときに警告しないため、意図的なアプローチは何十時間も節約し、3アクト前にルートが封印されたことに気づくフラストレーションを防ぎます。[Phantom Blade Zero Beginner Guide](/ja/guides/beginner-guide/)は、主要な決定をブランチテストするために章ごとに3つのセーブスロットを使用することを推奨しています。これにより、全体のアクトを再プレイすることなく、安全にテストでき、YouTubeウォークスルーに頼らずに8つのエンドリングすべてを体験したいプレイヤーにとって最も安全な方法です。

### 推奨プレイ順序

8つのPhantom Blade Zero サイドクエスト エンドリング ルートをすべて解放するための実用的なスケジュールは以下の通りです：

| プレイ | 焦点 | 解放されるエンドリング |
|---|---|---|
| Run 1 — 忠義の刃、前向き | レッドレイスを完了、魏晨を許す | 2つのエンドリング |
| Run 2 — 忠義の刃、否定的 | レッドレイスに裏切る、魏晨を処刑 | 1つの新規エンドリング |
| Run 3 — ジェード登天、両方の結果 | ジェード秩序に味方し、交渉を切り替える | 2つの新規エンドリング |
| Run 4 — ファントム追放、両方の結果 | 協会に裏切り、交渉を切り替える | 2つの新規エンドリング |
| Run 5 — NG+ Eternal Cycle | 矛盾したフラグを引き継ぐ | 1つの新規エンドリング |
| Run 6 — NG+ Severed Path | すべてのフラグを浄化し、クリーンに歩む | 1つの新規エンドリング |

この計画は8つのエンドリングを6回のプレイに分散させ、最後の2回はNG+がなければ存在しません。プレイ回数を最小限にしたいプレイヤーは、ジェード秩序の決定と協会の決定の前にセーブすることでRun 3と4を統合できますが、同じセーブで両方の派閥パスを連続でクリアしようとすると、アクト3後半の戦闘難易度が大幅に上昇します。

### セーブスクーミング vs クリーンリプレイ

レッドレイスのクエストと魏晨の決定の前のセーブスクーミングは、ゲームにゲーム内の元に戻す機能がなく、開発者がこの慣行をパッチしていないため、コミュニティで広く受け入れられています。クリーンな1回のプレイを好むプレイヤーは、最終ボスアリーナに入る前に包括的なチェックリストに集中すべきです。なぜなら、アリーナに入ると、エンドリングがロックされ、異なるフラグを選択して戻る方法がなくなるからです。クリーンリプレイ法は、フラグ要件をすでに知っているプレイヤーに最適で、セーブスクーミングは6回の完全なキャンペーンをプレイせずに8つのルートすべてを見たい完璧主義者にとってより高速なパスです。

## よくある質問

**Phantom Blade Zeroには何つのエンドリングがありますか？**

8つのエンドリングがあり、4つの主要分岐に正と負の解決がそれぞれ付いており、さらに2回目のプレイで前回のプレイからの引き継ぎフラグを必要とするNG+固有のルートであるEternal CycleとSevered Pathがあります。

**サイドクエストは本当にPhantom Blade Zeroのエンドリングを変えますか？**

はい、24のサイドクエストのうち11つがエンドゲームフラグの重みを持ち、レッドレイスチェーンのような重要なクエストを見逃すと、最終アクトが始まる前にエンドリングの全体の分岐が永久にロックされるため、盲プレイでは典型的に5つか6つのエンドリングしか解放されません。

**1回のプレイで全エンドリングを得ることができますか？**

いいえ、NG+でのみ満たせる矛盾したフラグ組み合わせを必要とするルートがあるため、理想的な条件下で完璧なサイドクエスト完了をしても、1回のプレイで最大6つのエンドリングに制限されます。

**エンドリングにとって最も重要なサイドクエストは何ですか？**

忘れられた神殿でのレッドレイスの決定が、最もレバレッジの高いクエストです。これはフィナーレのトーンを直接決定し、8つの可能な結末の1つをロックするため、キャンペーン全体で最大の分岐点となります。

**NG+での選択はエンドリングに影響しますか？**

はい、NG+はエンドゲームフラグと部分的なNPC記憶状態を引き継ぐため、2回目のプレイでの選択は前回のプレイのデータと相互作用します。これが2つの固有のエンドリングがアクセス可能になる方法であり、なぜ2回目のプレイでは1回目よりもルート計画がより重要になるのかを説明しています。
